🔐 VULNERABILITY SUMMARY

WHAT'S VULNERABLE:
  ❌ GET /documents/{id} - No ownership verification
  ❌ PUT /documents/{id} - No prior authorization check
  ❌ DELETE /documents/{id} - No permission verification

WHAT'S SECURE:
  ✅ GET /documents/user/{userId} - Returns only user's docs
  ✅ POST /documents/create - Properly associates with creator
  ✅ JWT validation - Correctly identifies logged-in user
  ✅ Password hashing - BCrypt used

ROOT CAUSE:
  Backend authenticates users (proves WHO you are)
  But doesn't authorize what they can access (WHAT they can do)
  Result: Any logged-in user can access/modify/delete ANY document

THE FIX:
  Before GET/PUT/DELETE, add ownership check:
  
  if (!document.ownerId.equals(currentUser.userId)) {
      throw new UnauthorizedException("Access Denied");
  }
